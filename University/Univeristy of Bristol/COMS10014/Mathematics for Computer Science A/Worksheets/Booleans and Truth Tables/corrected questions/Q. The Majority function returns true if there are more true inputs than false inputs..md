For the majority function, if there are three inputs $p,q,r$ and there are more true inputs when 2 of the inputs are true. Thus in this case, it is the pairs $(p \land q), (p \land r)$ and $(q \land r)$. Thus the function can be expressed as:
$$
Maj(p,q,r) \equiv (p \land q) \lor (p \land r) \lor (q \land r)
$$
