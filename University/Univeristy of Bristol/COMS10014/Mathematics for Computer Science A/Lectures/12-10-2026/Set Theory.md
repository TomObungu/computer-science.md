# Operators on sets
The union of two sets the set of containing all the elements $A$ together with the elements $B$. It's symbol is denoted as as $A \cup B$

The intersection of two sets $A$ and $B$ the elements which are both in $A$ and $B$ i.e elements common to $A$ and $B$. It's symbol is denoted as $A \cap B$

The complement of a set a $A$ is the set of consisting elements not in $A$. It denoted as $A^{C}$

The difference between $A$ and $B$ denoted $A \setminus B$. It is set of elements in $X$ that are not in $Y$.
