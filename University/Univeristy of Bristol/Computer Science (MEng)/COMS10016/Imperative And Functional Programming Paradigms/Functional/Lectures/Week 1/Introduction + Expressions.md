# Functional Programming
Functional programming is a programming paradigm that focuses on applying, composing and manipulating functions but many modern language features are associated with this paradigm. 
# Language Laboratory
Functional languages are a petri-dish for programming language features that are later adopted by other languages. For example for garbage collectors (Python, Java, C#...), higher order and anonymous functions (C++, Java, C#, Rust), list comprehension (C#, Python, Scala), type classes (C++, Rust, Scala) and pattern matching (Rust, Java, C#...)
