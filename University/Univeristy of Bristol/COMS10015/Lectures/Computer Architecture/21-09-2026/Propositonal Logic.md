A proposition is basically a statement which adheres to some simple rules. Such propositions can have meaning which can:
1. Be evaluated to produce a turth value
2. Must be unambigious 
3. Include free variables, which must be bound ot concrete values
4. Can be represented using a short-hand variable or function. 

Example short-hands include:

For example the variable $f$ can be expressed as 
$$
f = \text{the temperature is 20} ^ \circ
$$
A function with the variable $x$ can be expressed as this closed short-hand expression:
$$
g(x) = \text{the temperature is } x ^\circ
$$

## Question
How can such statements be represented?

## Answer
Single statements can be combinued using various connectives e.g. $¬$

1. For example the statment "not x" is denoted by $¬x$
2. The statement "x and y" is expressed as $x \wedge y$
3. The inclusive-or operator is denoted as $x \lor y$ 
4. The statement for "x or y but not x and y" is denoted as $x \oplus y$
