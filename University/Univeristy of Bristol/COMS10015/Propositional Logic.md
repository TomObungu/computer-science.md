# Propositions
A proposition is statement whose value can be evaluated to either true or false. A proposition can involve two or more variables. Values assigned to the variables allow the proposition to be evaluated. 

For example the statement: "The temperature is $90^\circ$", is a propositon as it it can either be true or false.

However the statement: "turn off the heat" is a command or request of some kind, it does not evaluate to a truth value. Propositions must be well-defined in that they are definetly true or false. 

Furthermore statements like "90$^\circ$ is too hot"  is an impartial proposition as it could be true or false depending on context. 

Propositons must also have no "grey areas" in between. 

However some statements seem to be propositonal but cannot be evaluated because they are paradoxical. A famous example:

"A man says he is lying, is what he says true of false?"

## Propositonal functions
A propositional function is just a short-hand way of writing a proposition, we give the function a name a list of free variables. 

In this case the function $g$ can hold the proposition:
$$
g: \text{The temperature is 90} ^\circ
$$

For futrue cases, you can use the notation the propositional function in further logic. 

Another example is writing a function:
$$
h(x) : x^\circ equals 90^\circ 
$$
