Ubuntu is developed by Canonical and is built on Debian and is known for its accessible design, large user community, and broad hardware and software support. 
![[Pasted image 20260714110222.png]]

Ubuntu has become a common starting point for people who want to learn Linux. 

It offers a polished installer, strong documentation, predictable releases and a large ecosystme.

# Ubuntu and Debian

Ubuntu inherits much of its package management model and software packaging approach from Debian. Learning how `apt` works in Ubuntu will also help understand other Debian based systems. 

## Releases
Ubuntu uses two main release types. It publishes a new release every six months and every two years which is a long term support or LTS release. 

# Package management 
As a Debian-based system, Ubuntu uses the `.deb` package format.
