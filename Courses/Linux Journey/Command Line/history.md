The `history` command is a fundamental tool in Bash and many Unix-like shell environments. 

To see list of commands you have used type `history`

Use `!!` to execute the most recent command again.


Press `CTRL-R` to initiate a reverse search and start typing.

`history -c` removes all entries from the history list in memory

`history -w` saves the current session's history to a history file called `~/.bash_history
