A shell is a program that accepts commands as you type, asks the OS to run them, and then prints the result back to your terminal. 

# Interacting with the Bash shell
Bash is short for 'Bourne Again Shell'. Bash is one of the most common Linux shells and is a good foundation even if you later use `zsh`, `fish` or another shell. 

# Commands
The `$` symbol indicates that the shell accepts input as a normal user. If you see `#` instead, you are a root user.
