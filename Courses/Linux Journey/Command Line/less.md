The `less` utility displays text in a paged format, allowing you to navigate through a file without flooding your terminal. 

Use arrows keys and page keys to navigate line by line. 

Press `g` to move directly to the beginning of a text file

Press `G` to jump to the end of a text file

Use arrow keys up and down to navigate line by line or page by page. 

Do `/` to search forward

Do `?` to search backward

`n` jumps to next occurence of search term

`N` jumps to previous occurrence of search term. 

Do `less -N` to show line numbers
