These commands allow you view the first and last few bits of a file. 

You can determine this using `-n` to determine the number of lines

for example running this with `-n` as only outputs the first line of  a file

```bash
head -n 1 myfile.txt 
removed './.var/app/org.vinegarhq.Sober/data/sober/assets/content/sounds/action_get_up.mp3'

```
