Arch Linux is a lightweight, independently developed Linux distribution known for user control and a hands-on approach.

![[Pasted image 20260714123154.png]]


# Rolling Release
Arch uses a rolling relase model, so packages are updated continuously. This gives users to current software without reinstalling the system for each major release. This means updates require more attention than on conservative point-release distros. 

# Pacman and Package Mangement
Arch uses Pacman as its package manager. Pacman installs, updates, removes and tracks software on the system. 

A common command is `sudo pacman -Syu`, which synchronises package databases adn upgrades the installed system. 

# The Arch Philosphy
Arch is often associated with minimalism, modernity and user centrality. In practice, that means the distro tries to avoid unnecessary abstraction and expects users to take responsiblity for setup and maintenance. 

# Uses
Arch Linux is best suited for users who want a hands-on Linux distro and do not mind reading documentation.
