# Linux Mint and Ubuntu
Linux Mint is based on Ubuntu, especially Ubuntu LTS releases. This means it inherits a large software ecosystem, broad hardware support and mature package management. 

## Package Management 

As Linux Mint is Ubuntu-based. It uses the `.deb` package format and APT for package management. Users can install software from the command line or through graphical tools such as the software manager.
