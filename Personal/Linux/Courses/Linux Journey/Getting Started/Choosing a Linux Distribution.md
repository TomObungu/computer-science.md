A Linux system is divided into three main parts:
- Hardware - The physical components such as the CPU
- Linux Kernel - The core operating system. The kernel manages the hardware and and facilitates communication between software and hardware
- User space - The environment in where the user interacts with the system through applications

# Linux Distro
A linux distro bundles the Linux Kernel with system utilities, libraries, applications and a package manager. Many Linux distros also come with a desktop environment.
